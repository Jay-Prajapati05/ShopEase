# ShopEase

Full-stack e-commerce web application built with the MERN stack.

## Overview
ShopEase lets customers register, browse products, add items to a
cart and place orders. Admins manage products and orders from a
separate panel. The goal is a production-ready, deployed app.

## MVP
Register/login, browse products, cart, and Cash on Delivery orders.
Admin can add and manage products.

## Planned features
- JWT authentication and role-based access
- Product search, filters and pagination
- Order history and order status
- Razorpay payments (test mode) and Cloudinary image upload
- Admin dashboard, reviews and ratings

## Tech stack
MongoDB, Express.js, React (Vite), Node.js, Tailwind CSS

## Project structure
- server/  - REST API (Express + MongoDB)
- client/  - React frontend
